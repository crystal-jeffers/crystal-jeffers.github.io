# crystal-jeffers.github.io

Portfolio landing page. Published at https://crystal-jeffers.github.io/

- `index.html`: the whole page. Project cards are marked with comments (`<!-- 1. Employee Lifecycle -->` etc.).
- `assets/style.css`: shares the palette of the Start-Up SOP and Employee Lifecycle sites.
- Screenshots load straight from those two sites, so updating a screenshot there updates it here.

To add the PM Parts write-up, replace the `upcoming` card (`id="pm-parts"`).
